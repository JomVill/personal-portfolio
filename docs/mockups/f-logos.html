Three marks for “jom”

Each is built from one idea: a workflow node and a connector. Ink plus one orange accent. Shown at 16, 32, 64 and 160 px, on light and dark, and in a header.

Option 1 · in e2 header

The o is a node

Lowercase “jom” in a geometric monoline. The o becomes a rounded node box in orange, fed by one wire from the j’s dot, like a step in a workflow. At favicon sizes it reduces to “jo”: the j plus its orange node.

Option 2

j + node

A compact square mark: the j’s dot is an orange node, the j itself is the wire, and it ends in a port. Built for the favicon first. It pairs with “jom” set in Manrope, so the mark and the name stay separate.

Option 3

The orange key

“jom” on a rounded-square key, the way the site’s active key is orange. Flat, no shading, so it holds up as an app icon. The same key on light and dark. At favicon sizes it carries the j alone.
